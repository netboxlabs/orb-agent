# orb-telemetry

Orb telemetry backends collection

- [snmp-telemetry](./snmp-telemetry/README.md) - Metric collection over SNMP using [ktranslate-compatible profiles](https://github.com/kentik/snmp-profiles).
- [gnmi-telemetry](./gnmi-telemetry/README.md) - Streaming metric collection over gNMI using metric profiles.
